# A part for the i8042 slot, on the HP

The pre-registration of ring 8b (`stage8/plan-8b.md`). Written and committed
before any grow; frozen before any grow. Its git commit is its timestamp. A
plan amended after a failed verdict is a new pre-registration, a new commit,
by the owner's word. `stage8/bench.py` reads these headings cold.

## Intent

Fewer instructions on the human's input path, for this machine. The seed's
generic i8042 decoder is written for every PS/2 controller and every set of
keys. This part is grown for one machine and may use what is true of it.

## Identity

`cpu 000306a9 pci 8086:1e47:04`

The HP's own, from ring 8a's closure: its CPUID signature and its LPC bridge.
The part is for this machine only. It is keyed to this identity in the
germline, and the guest reads its own identity at the request, so the part
reaches no other machine.

## Contract

The part is `stage8/PARTS.md`'s, ABI 3, slot `i8042`: the header, the three
entries `init`, `byte` and `health`, the calling convention and the service
table, all as that document says. Its behaviour is the generic's exactly:

- `init` does the controller's cold init and the mouse's reset, identification and enable, as `mouse_init` does, with the ordering of ring 7c item 15 (both ports off and drained after the self-test, before the command byte is read);
- `byte` never touches a port. Status bit 5 says the byte is the mouse's;
- `E0` swallows its successor, whatever the successor is. An `E0` following an `E0` is that successor;
- the shift state follows `2A` and `36` makes and `AA` and `B6` breaks; a break code otherwise does nothing;
- a make code goes through scancode set 1's two US maps, each 128 bytes, verbatim as `stage8/fixtures/i8042-good.asm` has them; a code whose map entry is 0 makes no key;
- `E1` has no meaning of its own: it is a break code, so it is ignored, and the bytes after it are decoded as any others;
- a mouse packet is three bytes. A first byte without bit 3 set is dropped and the machine waits for a first byte again. `dx` and `dy` are the second and third bytes sign-extended, with `dy` positive upwards; `buttons` is the first byte's low three bits; the overflow and sign bits of the first byte are not interpreted;
- a key's stamp is the stamp of the byte that completed it; a packet's stamp is the stamp of its first byte;
- keyboard and mouse bytes each have their own state: a mouse byte arriving inside an `E0` does not end it, and a keyboard byte arriving inside a packet does not end it;
- all state lives inside the part and is valid as stored, because in shadow `byte` is called without `init` ever running;
- `health` answers 0, or a failure code if `init` failed.

## Corpus

The bytes the bench feeds, in order, each a `(status, byte)` pair. The block
below is the corpus: `corpus()` is what `bench.py` runs. Keyboard bytes have
status `0x15`, mouse bytes `0x35`.

```python
def corpus():
    out = []
    K, M = 0x15, 0x35

    def k(*bs):
        for b in bs:
            out.append((K, b & 255))

    def m(*bs):
        for b in bs:
            out.append((M, b & 255))

    def pkt(buttons, dx, dy, ox=0, oy=0):
        m(0x08 | buttons | (0x10 if dx < 0 else 0) | (0x20 if dy < 0 else 0)
          | (0x40 if ox else 0) | (0x80 if oy else 0), dx, dy)

    # 1. Every make and break code, each make followed by its break.
    for code in range(0x80):
        k(code, code | 0x80)

    # 2. Both shifts around every make.
    for shift in (0x2A, 0x36):
        for code in range(0x80):
            k(shift, code, code | 0x80, shift | 0x80)

    # 3. E0 before every byte value.
    for value in range(0x100):
        k(0xE0, value)

    # 4. The E1 pause sequence.
    for _ in range(4):
        k(0xE1, 0x1D, 0x45, 0xE1, 0x9D, 0xC5)

    # 5. Typematic runs: a held key repeats its make and breaks once.
    for code in (0x1E, 0x1F, 0x20, 0x39, 0x1C, 0x0E, 0x02, 0x10):
        k(*[code] * 24, code | 0x80)
    for code in (0x48, 0x50, 0x4B, 0x4D):       # the arrows, E0 before each make
        for _ in range(12):
            k(0xE0, code)
        k(0xE0, code | 0x80)

    # 6. Packets with every button, every sign and every overflow bit.
    for buttons in range(8):
        for dx in (0, 1, -1, 127, -128):
            for dy in (0, 1, -1, 127, -128):
                for ox, oy in ((0, 0), (1, 0), (0, 1), (1, 1)):
                    pkt(buttons, dx, dy, ox, oy)

    # 7. A lost byte in the middle of a packet, and the resync after it.
    for dx in range(1, 61):
        pkt(0, dx, 2)
        m(0x08 | 1, dx)                         # its third byte is lost
        pkt(0, dx, 3)                           # so this one is read out of step
        m(0x00, 0x01, 0x02)                     # bytes that cannot begin a packet
        pkt(1, 4, dx)

    # 8. Keyboard bytes between mouse bytes, and inside an E0.
    for i in range(1, 101):
        first = 0x08 | (i & 7)
        k(0xE0)
        m(first)
        k(0x10 + (i % 26))                      # the E0's successor, mid-packet
        m(i)
        k(0x10 + (i % 26))                      # a plain make, mid-packet
        m(-i)
        k((0x10 + (i % 26)) | 0x80)

    # 9. A run of plain typing and of pointer motion.
    text = ("the quick brown fox jumps over the lazy dog while the night "
            "nurse writes a note about the fever and the small cough ")
    keys = {c: s for s, c in enumerate(
        "\0\0" "1234567890-=" "\0\0" "qwertyuiop[]" "\0\0" "asdfghjkl;'`" "\0\\" "zxcvbnm,./", 0)
        if c != "\0"}
    keys[" "] = 0x39
    for repeat in range(6):
        for c in text:
            k(keys[c], keys[c] | 0x80)
        k(0x1C, 0x9C)
        k(0x2A, keys["a"], keys["a"] | 0x80, 0xAA)

    # Keyboard and mouse bytes near equal in number, so that the median is
    # not one device's: pointer motion, a small deterministic walk, to level.
    x, y = 1, -1
    while True:
        kb = sum(1 for s, _ in out if s == K)
        if sum(1 for s, _ in out if s == M) + 3 > kb:
            break
        pkt(0, x, y)
        x = (x * 3 + 1) % 17 - 8
        y = (y * 5 + 3) % 13 - 6
    return out
```

## Measures

Under `-icount shift=0,sleep=off` the TSC counts instructions. The **cost of
a byte** is the instructions from the `byte` entry to the first upcall that
byte makes, or to its `ret` if it makes none, less the cost of a null decoder
measured in the same boot. Each decoder gets four blocks, alternated, each
from a fresh copy; every block must give the same costs as every other block
of the same decoder, or the bench has failed and there is no verdict.

- **Primary:** the median cost per byte over the whole corpus (`median_low`).
- **Secondary, worst:** the largest cost of any byte in the corpus.
- **Secondary, size:** the part's whole size, `96 + B`.

The generic is `stage8/fixtures/i8042-good.bin`, the seed's own decoder through
the slot interface.

## Margins

- primary: 5
- worst: 5
- size: 5

Each is a percentage. The part's median must be at least the primary's margin
lower than the generic's. Its worst case and its size must each be no more
than their margin higher.

## Threshold

- boots: 3
- keyboard bytes: 1000
- mouse packets: 5000
- disagreements: 0
- probation: 3

Shadow on the machine itself, summed over three boots by `PARTS.md`'s rule,
then three healthy live boots.

## Candidates

- at most: 2

Any failure of a gate or a measure spends one. The second brief carries the
first's failure.

## Verdict rule

```python
def verdict(generic, part, margins):
    """generic and part are {"median": n, "worst": n, "size": n}; margins is
    {"primary": p, "worst": w, "size": s}, percentages. Returns ("beats" or
    "the generic stays", [one line for each measure])."""
    lines, ok = [], True
    if part["median"] * 100 <= generic["median"] * (100 - margins["primary"]):
        lines.append("primary: median %d against %d, at least %d%% lower: yes"
                     % (part["median"], generic["median"], margins["primary"]))
    else:
        ok = False
        lines.append("primary: median %d against %d, at least %d%% lower: no"
                     % (part["median"], generic["median"], margins["primary"]))
    for name in ("worst", "size"):
        if part[name] * 100 <= generic[name] * (100 + margins[name]):
            lines.append("secondary %s: %d against %d, no more than %d%% higher: yes"
                         % (name, part[name], generic[name], margins[name]))
        else:
            ok = False
            lines.append("secondary %s: %d against %d, no more than %d%% higher: no"
                         % (name, part[name], generic[name], margins[name]))
    return ("beats" if ok else "the generic stays"), lines
```
